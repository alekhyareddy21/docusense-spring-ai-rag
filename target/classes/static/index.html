AI & LLM Configuration

DocuSense AI is built with Spring AI and can use Google Gemini (free API), OpenAI, Groq, or local Ollama.

Get a free key from Google AI Studio. Set it in application.yml or environment variable OPENAI_API_KEY.

💡 Interview Tip: When presenting this project, highlight that you integrated:
  • Spring AI with Vector Store (Embedding Model + SimpleVectorStore / PGVector)
  • Apache PDFBox for multi-page document parsing and text chunking
  • Hibernate (Spring Data JPA) for relational mapping of users, document metadata, and chat history
  • Server-Sent Events (SSE) for real-time streaming tokens
